# How to Use Your Mini Minecraft Builder 🎮

## Quick Start
1. Open `index.html` in any web browser
2. The game will load with your Minecraft logo at the top
3. Start clicking on the grid squares to build!

## Game Controls

### Building Blocks
Click any square to cycle through these states:
1. **Empty** (beige/tan color)
2. **Grass** (green with grass texture)
3. **Stone** (gray with stone texture) 
4. **Wood** (brown with wood texture)

### Auto House Builder
- Click the **"🏠 Build a House"** button
- Watch as a simple house appears automatically
- The house will have:
  - Wood walls on the top and sides
  - Stone floor at the bottom
  - Empty spaces inside (including a "door" area)

### After Building a House
- You can still edit every square manually
- Click any square to change it to a different block type
- Create your own designs!

## Features for Kids

### Visual Feedback
- Squares glow when you hover over them
- Fun "building" animation when you click
- Bright, colorful design that's easy to see

### Simple Interactions
- Only one action needed: clicking
- Predictable results every time
- No complex menus or confusing options

### Learning Opportunities
- **Pattern Recognition**: Understanding the cycle of block types
- **Spatial Awareness**: Working with a grid layout
- **Cause and Effect**: Clicking produces immediate visual changes
- **Creativity**: Free-form building and design

## Technical Notes

### Browser Compatibility
- Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- Also works on tablets and smartphones
- No plugins or downloads required

### Customization
- All code is in simple HTML, CSS, and JavaScript
- Easy to modify colors, sizes, or add new features
- Well-commented code for learning

## Troubleshooting

### If Images Don't Show
- Make sure all image files are in the `assets/` folder
- Check that file names match exactly (including spaces and capitalization)
- Try refreshing the browser

### If Clicking Doesn't Work
- Make sure JavaScript is enabled in your browser
- Try refreshing the page
- Check browser console for any error messages
