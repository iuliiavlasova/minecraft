# How to Use Your Enhanced Mini Minecraft Builder 🎮✨

## Quick Start
1. Open `index.html` in any web browser
2. The game loads with beautiful Minecraft logo and layer controls
3. Start on **Layer 1** and begin clicking grid squares to build!

## 🎯 Building Controls

### **Block Cycling**
Click any square to cycle through **5 block types**:
1. **Empty** (tan/beige - like dirt or air)
2. **Grass** (green with grass texture)
3. **Stone** (gray with stone texture) 
4. **Wood** (brown with wood texture)
5. **✨Diamond** (sparkling blue with special effects!)

*See the preview row at the bottom to know what comes next!*

### **Layer Navigation**
- **⬆️ Layer Up**: Build higher floors (up to 8 layers!)
- **⬇️ Layer Down**: Go to lower floors  
- **Current Layer**: Always shown clearly at the top (Layer 1, 2, 3, etc.)

### **Building Tools**
- **🏠 Build a House**: Creates an amazing 3-layer house automatically!
- **🧽 Clear Layer**: Removes all blocks from the current layer only

## 🏠 Multi-Layer House Builder

When you click **"🏠 Build a House"**, watch the magic happen:

1. **Layer 1**: Stone foundation appears first
2. **Layer 2**: Wood walls with doorways are built  
3. **Layer 3**: Wood roof with sparkling diamond decorations!

After it's built, you can:
- **Navigate between layers** to see each floor
- **Edit any square** on any layer
- **Add your own decorations** and modifications

## 🎮 Play Strategies

### **For Young Children (Ages 5-7)**
- Start on Layer 1 and just experiment with clicking
- Try to fill the whole grid with one type of block
- Use the house builder to see what's possible
- Focus on one layer at a time

### **For Older Children (Ages 7+)**
- Plan multi-layer buildings: foundation, walls, roof
- Create different rooms on different layers
- Try building tall towers using all 8 layers
- Mix diamond blocks for special decorations

### **Parent-Child Building**
- **Take turns**: Parent builds foundation, child adds walls
- **Tell stories**: "This diamond is a magical crystal!"

## 🚨 Troubleshooting

### **If images don't show:**
1. Check that `assets/` folder contains all image files
2. Refresh your browser (F5 or Ctrl+R)
3. Make sure file names match exactly (case-sensitive!)

### **If layer buttons don't work:**
1. Make sure JavaScript is enabled in your browser
2. Try refreshing the page
3. Check browser console (F12) for error messages

### **If animations seem slow:**
1. Close other browser tabs to free up memory
2. Try a different browser
3. Restart your browser
